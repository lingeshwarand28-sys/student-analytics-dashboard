# 🎓 Student Academic Performance & Placement Analytics

A data analytics project that analyzes student academic performance and placement-related data using Python, Pandas, SQL and Streamlit.

## 📊 Features

- Student academic performance analysis
- Department-wise CGPA analysis
- Attendance analysis
- Internship analysis
- Placement analysis
- Interactive filters
- Student data search
- CSV data download
- Interactive dashboard

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- SQLite
- Streamlit
